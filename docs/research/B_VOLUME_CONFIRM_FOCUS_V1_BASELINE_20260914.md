## Fixed experiment definition

`B_VOLUME_CONFIRM_FOCUS_V1` uses exactly one membership rule:

```text
focus iff candidate.vol_ratio >= 1.20
```

The threshold is frozen before the prospective epoch. Missing, null, non-finite, or non-numeric
`vol_ratio` is not focus. No Score, stop distance, market grade, sector, repeat ticker, turnover,
signal-day change, RR, target type, or T+1 target touch is a hard filter. Canonical B candidate
identity, order, Score, trigger, stop, target and RR remain unchanged.

Prospective epoch: `FIRST_GENUINE_T_CLOSE_RUN_AFTER_DEPLOYMENT`. The first successful production
tracker step records this date in the existing `perf_tracker.json` metadata; it does not backfill
older lists and does not create a second tracker. Review gate is fixed at both:

- at least 20 XSHG trading sessions; and
- at least 20 triggered samples in cohort A (`vol_ratio >= 1.20`).

Before the gate, status is `EVIDENCE_ACCUMULATING`; no result can change formal B automatically.
